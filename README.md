## 项目

| 目录 | 内容 | 博客 |
| --- | --- | --- |

## 每个项目的约定

- `技术博客.md`：正文，公式用 LaTeX
- `*.py`：可直接运行，博客里的每个结论都能复现
- `*.csv` / `*.png`：实验原始数据与出图
